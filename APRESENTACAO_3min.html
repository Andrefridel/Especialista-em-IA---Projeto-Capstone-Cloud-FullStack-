① Introdução — O que foi construído
"O projeto que desenvolvi se chama BookWorm — uma plataforma completa de e-commerce para compra de livros, construída do zero seguindo exatamente o Use Case apresentado nos slides da atividade.

O sistema cobre toda a jornada do cliente: desde o login, passando pela navegação no catálogo, seleção do produto, carrinho de compras, até o pagamento e a confirmação do pedido.

Todo o desenvolvimento foi feito com o apoio do IBM BOB como Agentic IDE — o agente gerou o código do backend, o schema do banco de dados, a especificação OpenAPI e todas as telas do frontend."
💡 Antes de começar: abra o navegador com o arquivo frontend/index.html já carregado.

③ Tecnologia — Como foi construído
"O sistema é composto por três camadas:

O frontend foi construído em HTML5, CSS3 e JavaScript puro — sem frameworks, acessível direto no navegador.

O backend é uma API REST em Node.js + Express com 19 endpoints documentados em OpenAPI 3.0, navegáveis pelo Swagger em localhost:3001/api-docs.

O banco de dados é PostgreSQL com 11 tabelas — usuários, livros, categorias, carrinho, pedidos, reviews, endereços e cupons.

A autenticação usa JWT. O código foi gerado com o IBM BOB seguindo os 9 steps do workflow dos slides."
